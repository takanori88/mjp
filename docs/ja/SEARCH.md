# 文書内検索

[English](../en/SEARCH.md) · [README](README.md#文書内検索)

検索は Vim 風の操作に従います。一致を本文に重ねる色付きの箱で示し、現在の一致はより濃い色にします。検索欄を開いたときの閲覧位置を保存し、入力すると一致を更新して、その位置での閲覧範囲の上端以降にある最初の一致へ移動します。バナーと検索欄の遮蔽も考慮し、後ろに一致がなければ先頭へ巡回します。既存の検索語で開き直した場合も、新たな閲覧位置から一致を選び直します。現在の一致が画面の上端や下端の近く、または画面外にあるときは、ウィンドウの中央へスクロールします。

Enter で現在の一致に確定し、検索欄を閉じて本文へフォーカスを戻します。ハイライトは残り、現在の一致がある行の行末に `[3/12]` のような件数バッジを表示します。0件の検索語は `0/0` のまま編集を続けられ、空の検索語は検索欄を閉じて印を消します。検索欄を開いている間は欄内に現在位置と件数を表示します。保持する一致は先頭1000件までで、ちょうど1000件なら `3/1000`、超えた場合は `3/1000+`（バッジでは `[3/1000+]`）と表示し、保持した一致の範囲で巡回します。

確定後は検索欄を開かずに `n`／`N` で次／前へ移動します。現在の一致が画面外になるまでスクロールした場合、`n` は現在の閲覧範囲の上端以降の最初の一致、`N` は下端以前の最後の一致を選び、該当がなければ巡回します。現在の一致がすべて画面内なら、通常どおり次／前の一致へ進みます。

検索欄が開いているときの Esc は編集を取り消し、検索前の検索語、一致番号、印、保存したスクロール位置を戻します。検索欄が閉じているときの Esc は、表示中の印とバッジを消し、検索語と一致番号を保持します。`n`／`N` で印とバッジを再表示して移動でき、印がないときの Esc はプレビューを閉じます。検索欄が開いている間の `⌘F` は保存した位置を変えず、入力欄へフォーカスを戻して検索語を全選択します。検索入力欄では `j`、`k`、`q` などの閲覧用ショートカットは反応せず、IME変換中の Enter と Esc は入力メソッドに任せます。

検索対象は表示中の文書の描画後の文字列で、コード、表のセル、リンクの文字も含みます。大文字・小文字と全角・半角の英数字記号を区別せず、段落、リスト項目、表のセル、明示的な改行はまたぎません。読み込み対象のローカル画像の代替テキストは、読み込み失敗時も検索対象外です。外部画像や画像記法64個の上限を超えた画像の代替テキストは検索できます。

自動更新後も同じ語句で検索し、一致番号が範囲内なら維持し、それ以外は最初の一致へ戻します。この再検索では追加のスクロールを要求しません。箱とバッジは画像の読み込みなどによるレイアウトの変化に追従します。検索欄を開いている間はバッジを隠し、一致がなくなった場合は両方とも消します。

すべてのWebViewで同じ重ね描き方式を使い、本文の選択範囲はユーザーの操作に任せます。`⌘C` は WebView の通常の動作に従い、フォーカス中の入力欄または本文の選択範囲をコピーします。
